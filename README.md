# Recruitment Management System (RMS)

A full-stack Recruitment Management System developed as part of my Application Development coursework at Al Hussein Technical University (HTU).

The system was designed to simplify and centralize the recruitment process for both job applicants and HR staff.

## Project Overview

Applicants can browse job opportunities, submit applications, manage their profiles and CVs, and track their application status.

HR staff can manage job postings, review applicants, update application statuses, schedule interviews, and monitor recruitment activities.

This repository contains the core frontend and backend source code of the project, along with project documentation.

## Key Features

### Applicant
- User registration and login
- Browse available jobs
- View job details
- Apply for jobs
- Upload and manage CVs
- Track application status
- Manage personal profile
- Receive notifications

### HR Staff
- HR dashboard
- Create and manage job postings
- Review applicants and CVs
- View applicant details
- Update application status
- Schedule interviews
- Search and filter applicants
- Manage recruitment notifications

## Development Approach

The project was developed using an Agile approach:

**Sitemap → Wireframes → Mockups → Development → Testing → Improvements**

The frontend was implemented using React, while the backend was developed using Node.js and Express with PostgreSQL/Supabase for data management.
